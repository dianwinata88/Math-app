Question types

Every MathQuest level asks questions in one of six interactive formats. A level always uses the same format; the mix changes from level to level.

Multiple choice 611 levels

Tap the correct answer from a set of big friendly option cards. Options can be numbers, words, or emoji pictures.

Example levels

  • PreK: Which Has N? (Puppy Counting)
  • PreK: Find the Number (Doghouse Numbers)
  • PreK: Dice Dots (Doghouse Numbers)

…and 608 more levels.

Number pad 443 levels

Type the answer on the on-screen number pad and press Check.

Example levels

  • PreK: Type the Count (Counting Train)
  • PreK: Type the Teen (Counting Train)
  • PreK: Type the Sum (Snack Sums)

…and 440 more levels.

True or false 97 levels

Read the statement, then tap True or False.

Example levels

  • PreK: Zero Hero (Doghouse Numbers)
  • PreK: More or Not? (Treat Compare)
  • PreK: Is That Many? (Counting Train)

…and 94 more levels.

Match pairs 78 levels

Match every card on the left with its partner on the right — for example a numeral with its number word, or a coin with its value. The level self-judges once all pairs are matched.

Example levels

  • PreK: Match 3 (Match the Paws)
  • PreK: Match 4 (Match the Paws)
  • PreK: Match 5 (Match the Paws)

…and 75 more levels.

Order sequence 69 levels

Put the items in the right order by tapping them — smallest to biggest, first to last, or counting order. The level self-judges once the sequence is complete.

Example levels

  • PreK: Line Up 3 (Park Path 1–10)
  • PreK: Line Up 5 (Park Path 1–10)
  • PreK: Number Card Order (Counting Train)

…and 66 more levels.

Count & tap 42 levels

Count the pictured objects, then tap the option card showing that many.

Example levels

  • PreK: Count to 5 (Puppy Counting)
  • PreK: Count to 10 (Puppy Counting)
  • PreK: Count the Bones (Puppy Counting)

…and 39 more levels.
